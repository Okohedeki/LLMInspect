                        Guide

                        Adjust open-weights models, and see what changed

                        Pick an action in the top bar: what you want to do to the model. Each one runs as steps on three screens: Watch records the model at work, Trace finds the units behind a word and tests changes, Tune changes the weights, measures and exports. The bar at the top of each screen shows the step you're on, its tools and the next step. Do… (⌘K) searches every action and tool.

                        Brainscan shows functional measurements: logit-lens probabilities, direct logit attribution and projections onto contrast vectors built from example texts. Each readout is labelled by how it was built. Nothing here measures experience.
